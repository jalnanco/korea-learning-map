# 수학 개념 지도 (초1~고1)

개념 99개 = 고시문 수학과 「내용 체계」의 지식⋅이해 항목(원문 낱말 그대로). 선수관계 171개 — **원문 27** (고시문 문장이 밝힌 것, 실선) · **제안 144** (원문에 없어 Claude 가 제안하고 Gemini 가 반박 심사한 것, 점선 · <sup>제안</sup>).

> 원문: 「초⋅중학교의 지식⋅이해 범주는 학년(군)에 따라 위계성을 가지며, 영역 간에도 위계성을 고려하여 구성하였다.」 — 위계가 있다는 것은 원문이지만, 개념 사이 화살표 하나하나는 대부분 원문에 없다. 제안 간선의 이유와 심사 기록은 [concept_proposals.json](../data/kr/concept_proposals.json).

□ 셀프 체크는 그 개념 성취기준 문장을 물음으로만 바꾼 것이다. MCP 에서는 `concept_path` 로 묻고, 「예」인 개념은 `known` 에 넣는다.
